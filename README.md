Week 1: Applicant Data Cleaning
Fahad Tariq
Overview
This project uses Python and Pandas to clean and explore a fictional applicant dataset.
Tasks Completed
- Identified and handled missing values.
- Removed exact duplicates and repeated email records.
- Standardized domain names, statuses, and university names.
- Converted application dates to datetime.
- Cleaned phone formatting while preserving leading zeros.
- Validated and exported the cleaned dataset.
Files
- Week1_Data_Cleaning_Fahad_Tariq.ipynb — Notebook containing the cleaning process.
- applicants.csv — Original dataset.
- applicants_cleaned.csv — Cleaned dataset.
Results
The dataset was reduced from 82 to 77 rows, retaining all 7 columns. One invalid date was retained as a missing value.
Tools
Python, Pandas, and Google Colab.
